Overview

Purpose

The purpose of this site is to provide an intuitive, automated, and real-time digital scoreboard for the trick-taking card game Skull King, eliminating the need for manual pen-and-paper score tracking.

Audience

The target audience includes casual and competitive board gamers, families, and friends who play Skull King and want a seamless way to track bids, tricks won, and complex bonus points across all ten rounds.

Dynamic elements

Dynamic Round Tracking: JavaScript will dynamically alter the input form fields based on the current round (e.g., generating inputs for exactly 1 card/bid in Round 1, up to 10 cards/bids in Round 10).

Score Calculation Logic: The script will automatically calculate scores at the end of each round based on user-entered bids and actual tricks won, applying specific game rules (such as $+20$ points per trick for exact bids or $-10$ points per variance for missed bids).

Bonus Point Toggles: Dynamic checkboxes or drop-downs will allow players to easily add special bonus points earned during a round (e.g., capturing a Pirate for $+30$ points or the Skull King for $+50$ points), immediately updating the leaderboard.

Leaderboard Sorting: At the end of each round, JavaScript will recalculate totals and dynamically re-order a visual leaderboard table to display who is currently in the lead.

Pseudocode for your project


	// 1. INITIALIZE GAME STATE
	Initialize an array of player objects: { name: "", currentScore: 0, bid: 0, tricksWon: 0, bonuses: 0 }
	Set currentRound = 1

	// 2. ROUND SETUP
	FUNCTION startRound(roundNumber)
		Display input fields for each player to enter their "Bid" (0 to roundNumber)
		Hide the "Calculate Score" button until all bids are entered
	END FUNCTION

	// 3. SCORE CALCULATION
	FUNCTION calculateRoundScores()
		FOR each player object:
			Read input values for "Tricks Won" and any checked "Bonus Items"
			
			IF bid == tricksWon THEN
				IF bid == 0 THEN
					roundScore = roundNumber * 10
				ELSE
					roundScore = bid * 20
				END IF
				roundScore = roundScore + bonuses  // Add Pirate, Skull King, or Map bonuses
			ELSE
				IF bid == 0 THEN
					roundScore = roundNumber * -10
				ELSE
					roundScore = absoluteValue(bid - tricksWon) * -10
				END IF
			END IF
			
			player.currentScore = player.currentScore + roundScore
		END FOR
		
		UpdateLeaderboard()
		PrepareNextRound()
	END FUNCTION

	// 4. UPDATE INTERFACE
	FUNCTION UpdateLeaderboard()
		Sort the player array descending by currentScore
		Render the new rankings to the HTML scoreboard table
	END FUNCTION

	FUNCTION PrepareNextRound()
		IF currentRound < 10 THEN
			currentRound = currentRound + 1
			Trigger startRound(currentRound)
		ELSE
			Display final winner announcement and a "Reset Game" button
		END IF
	END FUNCTION
